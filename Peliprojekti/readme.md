Selviytyjä

Arttu Karinluoma


 kuvaa tarkasti pelin idean, tavoitteen, toimintaperiaatteet ja toiminnallisuudet sekä miten kestävän kehityksen näkökulma on otettu huomioon

- Pelissä valitaan taso: savanni, tundra tai viidakko

- Pelin tavoite on selvitä loppuun asti

- Pelissä tulee tapahtumia ja niistä kuuluu selvitä eteenpäin. Kun tapahtumia selviää tarpeeksi monta, tapahtuu jokin iso ja tarinaan vaikuttava tapahtuma, joka voi vaikuttaa tarinan lopetukseen.

- Kestävän kehityksen näkökulma on otettu huomioon pienillä tavoilla, esim. istuttamalla siemeniä.
